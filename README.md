# OrbCombat

A physics-based battle simulator for Android where unique orbs fight each other in an arena.

## Features
- 7 unique orb types each with special abilities
- Bet coins on match outcomes
- Cosmetic hat shop
- Random names powered by randomuser.me API

## How to Play
1. Select two fighters
2. Place your bet
3. Watch them fight
4. Win double your bet if your fighter wins

## Built With
- Godot 4
- GDScript
- SQLite (godot-sqlite plugin)
